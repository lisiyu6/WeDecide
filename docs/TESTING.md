## 实际发现并修复的问题

1. 需求 notes 输入框的 placeholder 少一个引号，后续 HTML 被吞进 textarea。真实浏览器只有 4 张卡且没有确认按钮；两个回归先失败再通过，修复后浏览器显示 5 张卡，可填写精确时间并确认 V1。
2. OpenAI 兼容配置填 /v1 时模型拉取正常，聊天却向 /v1 POST，返回 404。黑盒 HTTP 回归复现失败；补齐标准聊天端点后同一回归通过，浏览器也完成基址模型发现、选择、保存与 AI 草稿回填。
3. 窄屏卡片网格最小内容宽度撑大页面。浏览器记录 300 像素视口下页面宽约 503 像素；修复网格列收缩及按钮换行后无页面横向溢出。
